## 🔬 Project Overview

EEG signals carry rich information about brain activity and are widely used in clinical neuroscience for diagnosing neurological disorders, especially **epilepsy**. This project builds an end-to-end pipeline that:

1. **Loads** EEG signal data from the Bonn University EEG dataset (500 recordings × 4097 time points)
2. **Preprocesses** and normalises the signals with `StandardScaler`
3. **Extracts features** using Welch's Power Spectral Density (PSD) method
4. **Trains and compares** four ML classifiers (Random Forest, SVM, Naive Bayes, Decision Tree) via GridSearchCV
5. **Saves** the best-performing model and scaler as `.joblib` files
6. **Serves** a Flask web application where users can upload an EEG `.txt` file and instantly receive a class prediction with confidence scores

---

## 📊 Dataset Description

This project uses the publicly available **Bonn University EEG Dataset**, divided into five sets:

| Set | Label | Sub-folder | Subject State | Description |
|-----|-------|-----------|--------------|-------------|
| **A** | 0 | `SET A/Z/` | Healthy, eyes **open** | Surface EEG, relaxed wakefulness |
| **B** | 1 | `SET B/O/` | Healthy, eyes **closed** | Surface EEG, relaxed with eyes closed |
| **C** | 2 | `SET C/N/` | Epileptic patient, **non-seizure** zone | Intracranial EEG from opposite hemisphere |
| **D** | 3 | `SET D/F/` | Epileptic patient, **seizure** zone | Intracranial EEG from epileptogenic zone |
| **E** | 4 | `SET E/S/` | Epileptic patient, **during seizure** | Ictal activity — active seizure |

- **Each set**: 100 single-channel EEG recordings
- **Each recording**: 4097 data points sampled at **173.61 Hz**
- **Total samples**: 500 recordings

> 📚 Dataset source: [Bonn University EEG Dataset](https://www.ukbonn.de/epileptologie/arbeitsgruppen/ag-lehnertz-neurophysik/downloads/)

## 🚀 Getting Started

### Prerequisites

- Python **3.11+**
- `pip` package manager
- (Optional) A virtual environment tool (`venv` or `conda`)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/EEG_Classifier_Project_New.git
   cd EEG_Classifier_Project_New
   ```

2. **Create and activate a virtual environment** (recommended):
   ```bash
   python -m venv venv

   # macOS / Linux
   source venv/bin/activate

   # Windows
   venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Install additional training dependencies** (only needed for re-training):
   ```bash
   pip install scikit-learn matplotlib PyWavelets
   ```

---

### Running the App Locally

> ⚠️ The pre-trained model files (`eeg_classifier_model.joblib` and `eeg_scaler.joblib`) must be present in the root directory before launching the app. If they are missing, run the training script first — see [Training the Model](#-training-the-model).

```bash
python app.py
```

The app will start on:  
**`http://0.0.0.0:5001`** → open [http://localhost:5001](http://localhost:5001) in your browser.

## 🏋️ Training the Model

> **Only required** if you want to retrain, or if the `.joblib` model files are missing.

1. Ensure the dataset is placed at the correct paths (update `base_path` in `train_save_model.py` to point to your local `dataset/` folder):
   ```
   dataset/SET A/Z/   → Z001.txt … Z100.txt
   dataset/SET B/O/   → O001.txt … O100.txt
   dataset/SET C/N/   → N001.TXT … N100.TXT
   dataset/SET D/F/   → F001.txt … F100.txt
   dataset/SET E/S/   → S001.txt … S100.txt
   ```

2. Run the training script:
   ```bash
   python train_save_model.py
   ```

3. The script will:
   - Load all 500 EEG recordings
   - Normalise the data with `StandardScaler`
   - Extract Welch PSD features (→ 129 features per sample)
   - Train **4 classifiers** with 5-fold cross-validated `GridSearchCV`:
     - Random Forest
     - Support Vector Machine (RBF kernel)
     - Gaussian Naive Bayes
     - Decision Tree
   - Evaluate each classifier (Accuracy, Precision, Recall, F1-Score)
   - Save the **best model** as `eeg_classifier_model.joblib`
   - Save the **scaler** as `eeg_scaler.joblib`

## 🖥️ Using the Web App

1. Launch the app (`python app.py`)
2. Open [http://localhost:5001](http://localhost:5001)
3. Click **"Choose File"** and select any EEG `.txt` file (e.g., `Z001.txt`, `S050.txt`)
4. Click **"Upload & Predict"**
5. The app displays:
   - **Predicted Class** (Set A / B / C / D / E)
   - **Confidence Scores** for all five classes (%)

### Sample Input Format

Each uploaded `.txt` file should contain one EEG amplitude value per line (4097 lines total):

```
-10
23
-5
112
...
(4097 values total)
```

Non-numeric lines are automatically skipped during parsing.

## 🤖 Model Details

| Property | Value |
|----------|-------|
| **Feature Extraction** | Welch Power Spectral Density |
| **Sampling Frequency** | 173.61 Hz |
| **FFT Segment Length** | 256 samples (`nperseg`) |
| **Feature Vector Size** | 129 PSD frequency bins |
| **Train / Test Split** | 80% / 20% (stratified) |
| **Hyperparameter Tuning** | GridSearchCV (5-fold CV) |
| **Classifiers Compared** | Random Forest, SVM (RBF), Naive Bayes, Decision Tree |
| **Best Model Selection** | Highest accuracy on held-out test set |
| **Scaler** | `sklearn.preprocessing.StandardScaler` |

## ☁️ Deployment

This project is **Heroku-ready** out of the box.

### Deploy to Heroku

```bash
# 1. Login to Heroku
heroku login

# 2. Create a new Heroku app
heroku create your-app-name

# 3. Add model files to git (if excluded by .gitignore)
git add eeg_classifier_model.joblib eeg_scaler.joblib --force

# 4. Commit and push to Heroku
git add .
git commit -m "deploy: EEG Classifier web app"
git push heroku main

# 5. Open the deployed app
heroku open
```

> **Note:** The `.joblib` model files are excluded from git by default (`.gitignore`).  
> Use `git add --force` to include them, or remove `*.joblib` from `.gitignore` before committing.

### Other Deployment Options

| Platform | Notes |
|----------|-------|
| **Render** | Works with `Procfile` and `runtime.txt` as-is |
| **Railway** | Auto-detects Flask apps; add start command `gunicorn app:app` |
| **AWS EC2 / GCP** | Use `gunicorn app:app` as the start command |
| **Docker** | Add a `Dockerfile` with `CMD ["gunicorn", "app:app"]` |
